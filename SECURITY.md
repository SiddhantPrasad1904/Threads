# Security reporting

Do not publish vulnerability details, API keys, passwords, screenshots or private work evidence in public issues.

Use the repository Security tab's **Report a vulnerability** button when available:
https://github.com/SiddhantPrasad1904/Threads/security/advisories/new

If private reporting is unavailable, open a public issue asking only for a private reporting channel. Include no vulnerability details or private data. General support uses GitHub Issues. No guaranteed response time or compliance certification is offered.

Thread previews are unsigned unless the release explicitly says otherwise. Verify release checksums. Source is private; bundled desktop code is not a cryptographic secret. Local work evidence is unencrypted by Thread; DPAPI protects saved API keys only. Organization deployments require their own real SSO/TLS/database/backup validation.
