# Thread data and privacy

This describes the 0.2.0 RC2 dev4 Windows development preview. It is not a hosted-service privacy policy.

**Local capture.** Thread observes permitted foreground process/title and screenshots only during an active Remember session. Start captures the current permitted foreground context. Pause and Stop invalidate in-flight results. Thread does not record keystrokes. Configured process exclusions apply. Browser-domain exclusions are unavailable; Pause before private browser sites. By default, Thread stops observation after 300 seconds without input and resumes after new input. This reads Windows' last-input timestamp; it does not record keys or clicks. Set the threshold to 0 to disable inactivity suppression.

**Local files.** The default profile is `%LOCALAPPDATA%\Thread`; Settings shows the current directory. It contains SQLite evidence, notes, WorkState versions, handoffs, settings, diagnostics, and screenshot cache. Work history and screenshots are not encrypted by Thread; Windows filesystem permissions protect them. Screenshot cache defaults to 256 MiB and supports a configurable quota. Old unprotected pixels are evicted first while event metadata remains. WorkState provenance references protect pixels. If protected frames fill the quota, new screenshot persistence fails visibly. Age cleanup may also remove optional pixel files. Backups and exports stay where you save them. Uninstall preserves the profile.

**AI processing.** AI is optional. Local capture does not require a provider. At Stop/Retry, or when the opt-in **Update WorkState while Remembering** option is enabled, selected screenshot evidence, titles, notes, timestamps/identifiers, current structured WorkState, and extraction instructions/schema go to the configured provider. The full profile/database is not sent. The update option is off by default; its default minimum call interval is 60 seconds. Pause and Stop terminate the local worker, but cannot recall data already submitted. OpenRouter routes requests to downstream providers. Their privacy, retention, and billing terms apply. Viewing saved Resume/history and exporting Markdown do not require AI calls.

**Organization sharing.** Organization functionality requires a separately hosted service. Personal screenshots, notes, and WorkState do not sync. A member must review and explicitly publish shared tasks/status or an optional handoff. The service operator and identity provider receive only data needed for explicit account/workspace operations and the content a member shares. This preview does not include a hosted organization service.

**Credentials.** Saved provider keys use Windows current-user DPAPI and are scoped to endpoint/environment variable. Keys are not intentionally written to JSON settings, logs, SQLite, or exports. Environment credentials take precedence. Code running as your Windows user can access that user's secrets; DPAPI does not protect against malware or account compromise. Keys may not transfer to another Windows user/computer. Remove saved keys in AI connection and separately clear environment variables.

**Diagnostics and export.** Local logs contain operational metadata. Capture-decision diagnostics use context hashes rather than raw titles, notes, or pixels. AI-call audit records provider/model, timing, usage, schema, and typed failure metadata, not prompts or credentials. No telemetry uploader or analytics service is included. Markdown export excludes screenshot binary data and internal prompts and redacts configured/common credential patterns. Arbitrary secret formats and values visible in screenshots may remain; inspect exports before sharing. Export does not mutate canonical SQLite state.

**Deletion.** Quit Thread before deleting its profile. For complete removal, delete the exact profile directory shown in Settings and any separate exports/backups. Thread does not erase secrets that users intentionally typed into notes, screenshots, or saved handoffs. Use Windows device encryption/BitLocker and account protections for additional at-rest security.
