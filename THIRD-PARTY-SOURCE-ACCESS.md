# Third-party source availability

The 0.2.0 RC2 dev4 draft contains a portable application ZIP and checksum. It does not currently claim to contain a matching corresponding-source archive for every bundled third-party component. Earlier candidate source archives, if present in the draft, may not match the exact dev4 binary versions.

The ZIP contains a versioned `licenses/DEPENDENCIES.json` inventory and included license text locations. These files help identify components but do not satisfy every possible source-availability obligation. The publisher must verify the exact native and Python dependency versions, licenses, notices, and source-access requirements before public distribution.

Do not treat this preview as a compliance determination. Contact the project through the repository's private security reporting flow for security issues; use GitHub Issues for general questions. Do not post credentials or private work evidence.
